ЯК ЗАПУСТИТИ ДЛЯ РОЗРОБКИ:
1. Встановіть Node.js (якщо ще не встановлено).
2. Відкрийте термінал у цій папці та виконайте:
      npm install
      npm run dev
3. Відкрийте в браузері: http://localhost:3000
